# Soldier

Soldier is a small 2D pixel-art arcade game. Play as a soldier in a dark forest and fight off the orcs.

## Controls

| Action | Controls |
| --- | --- |
| Move left | `A` or `Left Arrow` |
| Move right | `D` or `Right Arrow` |
| Jump | `W` or `Up Arrow` |
| Attack | `Space` or left mouse button |

## Run the game

Open this project in Godot 4.7 or later, then run the main scene (`scenes/game.tscn`) or press **F6** while it is open. The project is configured to launch the game scene with **F5**.
